{\LARGE\bfseries Une suite entière toujours multiple de sept}\par
\vspace{0.25em}\hrule\vspace{0.6em}

\section*{Récurrence}
Au rang zéro, $u_0=0$. Si $u_n=7k$, alors $u_{n+1}=8u_n+7=7(8k+1)$. La propriété est héréditaire.

\section*{Somme géométrique}
Pour $n\ge1$, $8^n-1=7(1+8+\cdots+8^{n-1})$. Le second facteur est entier. Le rang zéro se vérifie directement.
