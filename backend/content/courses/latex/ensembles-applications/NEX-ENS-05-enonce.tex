{\LARGE\bfseries Ce qu’une composition injective impose}\par
\vspace{0.25em}\hrule\vspace{0.6em}

Soient $f:E\to F$ et $g:F\to G$. Montrer que si $g\circ f$ est injective, alors $f$ est injective. Déterminer si $g$ est nécessairement injective. Étudier aussi le cas où $g\circ f$ est surjective.
